Overview

Purpose

The purpose of Duel Puzzle Academy is to give users a simple, interactive trading card duel puzzle experience. Instead of playing a full card game, users will solve short duel situations by choosing the best move from a small list of options. The site will help users practice basic decision making, reading card information, and thinking through battle outcomes.

Audience

The audience for this site is students, casual card game fans, and users who enjoy short logic puzzles. The site is designed for beginners, so each puzzle will include clear directions, simple card descriptions, and feedback after the user submits an answer. Users will not need to know every rule of a full trading card game to understand the puzzles.

Dynamic elements

The site will use JavaScript to display one duel puzzle at a time from an array of puzzle objects. Each puzzle object will include player life points, opponent life points, cards in the player's hand, cards on the field, answer choices, a hint, and the correct answer. Users will be able to select an answer, submit it, receive feedback, move to the next puzzle, and see their score update. JavaScript will also be used to show hints, check whether the selected answer is correct, and display a final results message after all three puzzles are completed.

Branding

Website Logo

The logo will be a simple text-based logo using the initials DPA for Duel Puzzle Academy. This keeps the design simple and avoids needing a complex custom image.

Typography

The site will use simple, readable fonts. Headings will use a bold sans-serif font to give the site a game-like feel, while body text will use a clean sans-serif font for readability. The design will focus on strong contrast, large buttons, and clear spacing so the puzzles are easy to use on both mobile and desktop screens.

Pseudocode for your project

Create an array called puzzle. Each puzzle will be an object with a title, difficulty, player life points, opponent life points, cards, choices, correct answer, hint, and explanation.

When the page loads, display the first puzzle. Use a function to render the current puzzle information on the page. Use array methods such as forEach to display the answer choices as buttons or radio options.

When the user selects an answer and clicks the submit button, check the selected answer against the correct answer stored in the puzzle object. If the answer is correct, display a positive message and increase the user's score. If the answer is incorrect, display a helpful message and explain why another move is better.

When the user clicks the next button, move to the next puzzle. If there are no puzzles left, display the final score and a short message based on the user's results.

Wireframes

The site will use one main page. The layout will change between mobile and desktop views. On mobile, the page will stack the puzzle information in one column. On desktop, the duel information and answer choices can be displayed side by side.

Landing Page / Puzzle Page

The landing page will introduce the app and immediately show the first duel puzzle. The page will include a header, short instructions, puzzle progress, card information, answer choices, hint button, submit button, feedback area, and next puzzle button.
